# 关于页配置与验收

## 操作

入口：“管理 → 关于页设置”，路径 /manage/about。修改页面标题、一句话介绍和 Markdown 正文；正文使用现有编辑器，右侧实时预览。头像维持前台原资源。

点击“保存并更新前台”后公开生效，不需要重新构建前台。一句话介绍同时成为 SEO description，页面标题同步进入 metadata。正文原始 HTML 不执行。

读取失败不能保存，可以重试。保存失败保留输入，不自动重试写操作。发生版本冲突时先复制需要保留的内容，再重新载入最新版本。离开或重新载入有未保存修改的页面会确认；保存过程中禁止重复提交和修改。

## 发布与回退

必须先发布前台/API，应用新增 AboutPage 表迁移并确认 readiness 返回 about-page-v1，再发布后台。本仓兼容检查会阻止缺少此能力的 API。保持已有备份恢复门槛：本次新增表会触发迁移流程，不能先发布后台再等待不存在的接口。

回退后台应用可以撤回本入口；保留新增数据库表及已保存配置。本轮未操作正式数据库或部署生产，正式发布后还需验证实际读取与保存。

## 验收

- 自动化：Jest 22 项通过（关于页 4 项），覆盖读取失败、版本提交、重复提交、冲突保留输入、重新载入确认和导航保护；tsc 和生产构建通过。
- 发布兼容与 HTTP 探活：6 项通过，含拒绝缺少 about-page-v1 的旧 API。
- 隔离环境：前台 MySQL blog_test / Redis，前台并发更新与版本冲突测试通过；Linux Node 24 / Chromium 真实前后台配对 20 项通过（无跳过），含安全预览、保存持久化、刷新后前台/SEO 同步、加载失败禁保存、无 JS 阅读及桌面/390px 移动截图检查。
