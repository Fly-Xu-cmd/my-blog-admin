# 写作恢复与文章版本

2026-11-19，第二轮。新增文章页与管理文章编辑器使用浏览器草稿；明确选择恢复/丢弃，不自动覆盖服务器最新内容。按 API 地址和管理员账号区分，各窗口独立保存；内容、创建幂等 UUID 和请求摘要一并保留，响应丢失后刷新恢复仍能重试原请求。修改请求后换键，成功后仅清理本窗口草稿。存储失败显示提示，保存/上传时限制冲突操作。

离开、刷新和关闭编辑器提醒未提交修改。笔记仍只管理发布状态/类型，同步正文由本地维护。

历史版本列表分页加载摘要，选择后读取完整快照；读取失败不能载入。载入标题、正文、摘要、封面后作者检查并手动保存，不修改 URL、发布状态或当前分类/标签/系列。新后台 PUT 携带读取时的 revision，409 保留当前输入，请重新载入最新内容或复制需要的正文。恢复旧浏览器草稿也保留原 revision，不能绕过冲突校验。

API 及 PostRevision 迁移先部署，后台兼容探活新增 post-revisions-v1，能力缺失则不切换静态文件。正式服务器无需安装后台/前台开发依赖。

验收：25 项 Jest、tsc、biome lint、生产构建通过；兼容与 Basic Auth 探活6项通过。隔离 Chromium 配对23项通过，包括封面与正文并行上传、两种完成顺序下保存及关闭保持保护，响应丢失后同键恢复和历史载入后手动保存。正式 API 与发布尚未验收。

回滚保留服务器 revision/历史表与创建幂等记录，回退上一兼容后台静态包；不删除浏览器草稿、不将旧历史自动发布。
