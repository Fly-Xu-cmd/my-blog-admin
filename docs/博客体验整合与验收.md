# 博客体验整合与验收

2026-11-20：按读者与作者的使用反馈收敛七轮迭代。交付改为前后台各一个以 main 为目标的总 PR；前台旧 #78–84、后台旧 #42–45 被总 PR 替代，保留此前评审与验证记录。两仓仍独立发布，前台 API 与兼容迁移成功后再发布后台。

## 最终功能

- 搜索只在顶部工具区弹框中使用，移除独立 `/search` 页面，保留 `/api/search`。AntD 搜索框、类型筛选、分组与分页；标题与匹配段落高亮，无正文命中时展示开头段落。点击结果居中定位对应正文块并短暂高亮；搜索定位优先于阅读位置恢复。旧请求和关闭弹框后的回复不能覆盖当前状态。
- 移除 PNG 分享卡片。正文末尾保留复制链接，支持的浏览器显示原生分享。GitHub 讨论方案待定，现有链接及配置保持原行为。
- 移除 `/reading`、清单 UI、清单 API 与无引用样式。只保留当前浏览器的轻量阅读位置：最多 30 条、30 天有效，不保存标题、正文或凭据。最近 7 天未读完的内容自动恢复，提供“从头阅读”；搜索 hash、浏览器后退和主动滚动优先。存储不可用不影响正文。
- 没有 Markdown 标题时不显示空目录，正文采用居中的阅读宽度。“从这里开始”的分界线属于栏目本身，删除主推文章不影响剩余入门文章和系列的栏目结构。
- 后台站点配置按顶部导航、首页介绍、联系方式、搜索摘要分区预览；编辑字段对应位置高亮，可切换手机/桌面与明暗主题。未保存预览不更新前台，搜索引擎摘要仅为布局示意。
- 私有反馈显示来源标题并链接原内容；内容隐藏时提供管理员完整预览，删除时明确提示，不能暴露给公开 API。
- 内容概览按文章、技术笔记、随笔、动态展示公开/草稿/总数，补充最近编辑、待处理反馈、首页入口失效提示，以及创建/首次发布 30 天趋势。首次发布统计不因再次发布重复。
- 数据分析提供 7/30 天统一范围、整段时间去重 UV、热门内容标题/链接/类型筛选、来源、搜索与阅读入口次数、反馈状态。UV 是浏览器标识估算；订阅入口点击不是订阅成功。

## 数据与性能

新增兼容迁移 `20261120010000_interaction_daily`，只新增按日/事件/目标汇总表，不改已应用迁移。记录白名单事件，不保存关键词、IP 或读者操作明细；并发计数由数据库原子更新，Redis 抑制同浏览器短时双击。公开目标必须仍公开；限流默认每可信来源 IP 每分钟 120 次，`INTERACTION_RATE_LIMIT` 可配置。依赖故障明确 503，不无限回源。

后台概览与统计缓存 60 秒，鉴权在缓存与数据库读取之前，管理响应 no-store。搜索数据库最多读取匹配附近 8192 字符用于 Markdown 段落解析，响应仅包含最多约 200 字符摘要和字符定位；分页计数与数据在同一快照，查询/事务仍有超时上限。未增加运行时依赖，正式服务器继续直接运行 CI 生成的 Next standalone。

后台部署增加 `experience-v1` 能力检查，防止先部署调用新接口结构的后台。前台部署与新增兼容结构核验成功后再部署后台。回退兼容 release 时保留新增表和历史统计/配置，不删除 uploads、反馈或写作版本。

## 验收

自动化、隔离联测、视觉预览、独立只读评审分别记录；正式服务器/数据库及生产内容审计不在本轮操作范围。测试仅使用 tests/compose.yaml 对应 MySQL 13316/blog_test 和 Redis 16386；本地预览使用独立 blog_preview，保留现有内容与配置。

- 实施方自动化：前台 Vitest 76/76，typecheck、lint、production build 通过，迁出源码目录的 standalone smoke 通过；后台 Jest 30/30、tsc、Biome lint、production build 通过，部署兼容与 Basic Auth 测试 6/6。后台保留三条既有非阻断 lint 警告。
- 实施方隔离联测：配对 Chromium 40/40，涵盖搜索弹框、Unicode/emoji/İ 精确高亮、长正文定位、同篇重复搜索、真实文档后退与后续阅读恢复、草稿隐藏、空目录、配置、反馈、写作恢复及并行上传。迁移仅应用于 blog_test 与本地 blog_preview。
- 中间失败与复核：一次 MySQL P1001 经隔离服务连接健康核查后通过，未降低并发断言；后退测试等待文档与 URL 稳定后仍明确断言 back_forward 和后续正常导航恢复，最终 40 项全部通过。
- 本地预览：前台 http://127.0.0.1:3197，后台 http://127.0.0.1:8000。保留原有内容、配置与两个封面，不重新 seed。readiness 含 experience-v1，前后台与封面 HTTP 200；/search、/reading HTTP 404。浏览器人工检查桌面搜索与正文跳转、首页栏目分界线、后台内容概览、文案对应预览及手机/暗色预览控件；手机搜索布局由自动化覆盖。
- 独立评审：复用“博客组件库与主题背景只读评审”会话，实施前各轮和本轮产品代码已有无阻断结论；最终测试 setup 与验收文档增量在提交前复核。评审为静态只读，以上自动化与浏览器验收由实施方执行。
- 未验收：正式数据库备份恢复、正式内容隐私审计及正式部署业务检查留到发布前；本轮未合并或部署生产。GitHub 评论接入继续待定。
