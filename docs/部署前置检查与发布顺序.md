# 自动部署与数据库备份

日常更新合并到 main 后：CI 检查通过 → 自动部署 → 健康检查 → 失败恢复上一版应用。保留手动 Run workflow → main 入口。旧的 BLOG_BACKUP_RESTORE_VERIFIED、BLOG_ADMIN_COMPAT_READY、BLOG_API_COMPAT_READY 已停用，不再需要手填就绪标志。

## 前台与 API

每次发布使用独立 release；已有 npm/Node 20 可准备 appuser 私有 Node 24/pnpm，保留全局版本及旧依赖。候选先安装依赖、生成 Prisma，使用与应用相同的环境判断迁移历史与 SQL 校验值。

- 无待执行迁移：跳过备份、恢复验证和 migrate deploy，直接健康切换。
- 有新迁移：服务器生成事务一致的 MySQL 备份，保存到私有 .deploy-state/<release-id>。只在检查确认有新迁移且客户端缺失时，才在支持 apt 的服务器自动安装 MySQL dump 客户端；普通更新不依赖客户端或 apt。服务器无需 Docker。
- 备份通过 SSH 临时传到 CI，使用同系列 MySQL/MariaDB 容器独立恢复；核对 SHA256、所有基础表的行数及 CHECK TABLE。容器无外部网络，结束删除容器和临时卷，CI 临时备份文件不会上传为 artifact。
- 验收结果绑定发布 ID、备份与迁移计划。正式迁移前再次检查，验收缺失、备份损坏、历史异常或计划变化均停止，旧应用保持运行。
- 成功后才执行迁移，切换 PM2 并检查实际发布标识和匿名内容接口；健康失败尝试恢复原应用配置。正式备份保留在服务器私有目录，不自动清理。

备份是迁移前时间点的快照；验证期间仍可能有业务写入。应用回退不会撤销数据库结构，也不会自动用旧备份覆盖后续写入。仅有合法迁移历史的已有库可自动升级，历史异常不自动基线化。支持 MySQL 5.7/8.0/8.4 与 MariaDB 10.6/10.11/11.4/11.8；未知版本、非 InnoDB 表、dump 权限不足等情况会停止并给出具名错误。特殊客户端证书连接仍需配置，不能为了发布而降低 TLS 验证。

## 后台

后台静态页面若由 Nginx Basic Auth 保护，在后台仓库 Repository secrets 配置 BLOG_ADMIN_HTTP_USERNAME、BLOG_ADMIN_HTTP_PASSWORD。这组值是浏览器访问站点时弹窗中的凭据，不是 API 的管理员 JWT 或 SSH 私钥。只在 CI HTTP 预检和远端切换/探活步骤传递，不提供给 pnpm 安装/构建，不进入 dist。HTTP 探活仅向配置的后台 origin 发送 Basic Auth，禁止重定向；API 兼容检查不附带它。生产凭据只经 HTTPS 发送。

CI 安装/上传前先检查后台 HTTP 访问，服务器切换前再检查一次。401 会明确显示失败阶段与两项 Secret 名称；缺失/错误的凭据在修改 dist 前停止。切换后的发布标识、页面和同源 JS/CSS 检查继续执行，失败仍恢复上一版文件。公开静态站点不需要配置 Basic Auth 凭据；保留现有 Nginx 访问保护。

CI 使用构建所用的 BLOG_API_BASE_URL（默认 https://admin.xylxf.xyz）检查正式 /api/deployment/readiness。API 必须声明匹配的契约和全部所需能力，并通过管理员配置与只读 schema 检查；旧版本、数据库故障和缺字段均不放行。后台在有界时间内等待 API 发布，超时停止，不写生产数据验证能力。实际切换前及最终健康检查都复查相同 API 地址；生产能力接口只有在当前 release 健康检查通过并提交 current 后才可用，候选或回退中的版本不提前宣布就绪。

上传静态产物到独立 releases/<id>/dist，再切换 dist 链接。首次把原 dist 目录保留为 legacy release；后续原子替换链接。验证 BLOG_ADMIN_SITE_URL（默认 https://admin.xylxf.xyz）的发布标识、首页及本地 JS/CSS 资源，失败恢复上一版链接。运行中的部署不会被新任务取消。

首次升级按前台/API → 后台执行，管理接口切换期间可能短暂出现旧后台调用失败。原先的人工兼容阶段及手填就绪标志已由用户确认的自动流程替代；安全鉴权不退回匿名写入。后台 API 检测不等于完整生产 CRUD 验收，首次上线后仍核对登录、发布/隐藏、系列和上传。

## 一次性配置与验收范围

沿用现有 ALIYUN_SERVER_IP/ALIYUN_SSH_KEY Secrets 和服务器数据库环境，不向聊天或仓库提交密码。SSH 私钥不能放在普通 Variables 中。非默认域名通过普通 BLOG_API_BASE_URL 与 BLOG_ADMIN_SITE_URL 配置，API 检测和后台构建使用相同地址。Nginx 继续读取 /home/www/my-blog-admin/dist，需要允许受控 releases 内的链接。

本轮测试仅连接 tests/compose.yaml 的隔离 MySQL。真实 dump/恢复、无迁移跳过、备份损坏、错误验收批次、迁移变化、准备失败、API 不兼容、静态资源失败及应用回退均有自动化覆盖。正式服务器尚未执行备份、迁移或发布；最终检查结果在配对 PR 记录。
